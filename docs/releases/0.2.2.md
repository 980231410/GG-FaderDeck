# FaderDeck 0.2.2

本版聚焦界面动线与设备下拉的可用性，并补充托盘图标的完整性标签说明。

## 界面

- 经典 / 主播模式开关移到窗口标题行右侧，三个页面都能一键切换；主播页顶部原有的「Sonar 模式」卡片改为一行说明文字，把首屏空间让给混音与设备。
- 切到经典模式时不会再提示「这里的音量作用于经典混音」以外的东西；切到主播模式时经典页仍保留原来的橙色提示条。

## 设备下拉

- 主播模式「设备」卡片中的「个人合成器」「麦克风输入」下拉只显示设备名称，悬停可看完整名称（此前会把「头戴式耳机 (HyperX Virtual Surround Sound)」截断成一行省略号）。
- 默认隐藏 `SteelSeries Sonar` 系列虚拟声卡，只保留物理设备；若本机没有识别到物理设备，会自动回退显示全部设备，避免下拉为空。
- 当前已绑定的设备如果不在过滤后的列表中，会被插到列表首位并作为选中项，保证界面与 Sonar 状态一致。

## 托盘图标

- 应用代码未变，只是把 UIPI 这件事写清楚：托盘图标由 `Shell_NotifyIcon` 注册，Windows 会拒绝低于资源管理器完整性级别的进程。若资源管理器本身以管理员身份运行，普通权限的本程序同样注册不上，表现为「任务管理器里有进程、托盘里没有图标」。
- 发布的两个 exe 均带 `High` 完整性标签，以适配这种「资源管理器已提升」的环境；普通权限桌面可执行 `icacls .\FaderDeck-0.2.2-win-x64.exe /setintegritylevel Medium` 改回。
