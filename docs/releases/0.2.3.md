# FaderDeck 0.2.3

本版把两种 Sonar 模式收进同一页，并调整主播模式的卡片顺序。

## 结构

- 去掉独立的「主播模式」页。主界面只剩「音量与设备」与「应用路由」两页，右上角的经典 / 主播开关直接切换「音量与设备」页的内容：
  - 经典模式：Master、Game、Chat、Media、Aux、Mic 的音量、静音、输出设备与 EQ；
  - 主播模式：设备、直播监听、混音目标（直播 / 监听两套混音）、入混音开关、硬件输出。
- 两种模式共用同一个滚动区域与滚动条，切换是瞬时的，不重建窗口。

## 主播模式

- 「设备」卡片移到最上方，个人合成器与麦克风输入直接出现在首屏。
- 该卡片的下拉只显示设备名（悬停看全名），默认隐藏 `SteelSeries Sonar` 虚拟声卡、只保留物理设备；没有物理设备时自动回退为全部设备。
- 移除了经典页的橙色提示条「当前为主播模式：这里的音量作用于经典混音」，因为经典内容只会在经典模式下出现。
