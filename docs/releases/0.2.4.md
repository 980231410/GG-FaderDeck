# FaderDeck 0.2.4

本版修复「用 FaderDeck 切经典 / 主播之后，GG 的 Sonar 页面显示不对」的问题。

## 根因

- `PUT /mode/{classic|stream}` 会真正切换 Sonar 的模式：重定向、混音分支、`/deviceOut` 都会按新模式重配。
- 但 GG 的渲染进程只在页面加载时读一次 `/mode`，Sonar 也不广播模式变更事件（`/sock` 只有音量、音频会话、设备状态等事件），所以 GG 会一直显示切换前的布局：
  - 切到经典后，GG 仍显示 Streamer 布局，「流式处理合成器」显示为空；
  - 切到主播后，GG 仍显示经典布局，各通道设备显示为空。
- 也就是说：Sonar 侧状态是对的，缺的是「让 GG 重新读一次」。

## 修复

- 模式写入成功后，FaderDeck 会重新载入 GG 窗口（`Ctrl+R`），GG 重新挂载 Sonar 页面并按新模式渲染；切换个人合成器 / 麦克风输入后同样刷新一次。
- 状态栏区分结果：
  - `已开启主播模式，GG 页面已刷新`
  - `已开启主播模式；GG 页面未能自动刷新，请重开 GG 或按 Ctrl+R`
- GG 没有运行时不会尝试刷新，也不会给出误导性提示。

## 注意

- 刷新 GG 会把 GG 页面带回首页，需要再点进 Sonar 查看。
- 如果 GG 以更高权限运行而 FaderDeck 是普通权限，`SetForegroundWindow` 会被 UIPI 拒绝，此时只能手动刷新——状态栏会如实提示。
