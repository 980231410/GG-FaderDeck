# 0.2.0

## 新功能

- 主播模式新增「设备」卡片：可直接切换 Sonar 的「个人合成器」（监听混音输出设备）与「麦克风输入」（麦克风重定向设备）。
  - 两个下拉框分别按 `render` / `capture` 方向筛选 `GET /audioDevices` 返回的设备，工具提示显示完整名称。
  - 写入使用 `PUT /streamRedirections/{monitoring|mic}/deviceId/{id}`，并用响应中的 `deviceId` 回读确认。

## 修复

- 在 FaderDeck 中切换 EQ 后，已打开的 SteelSeries GG 页面保持旧预设的显示问题。
  - 根因：GG 的 Sonar 页面只在自己发起切换时更新选中预设；Sonar 服务向 `/sock` 只推送音频会话与设备音量事件，不推送「选中预设变更」（已用落盘抓包验证），因此外部切换无法通过事件驱动 GG 重绘。
  - 处理：EQ 写入成功后触发一次 GG 窗口重新载入（Ctrl+R），页面重新渲染时会重新读取 Sonar 的最新选中项；托盘菜单同时提供「同步 GG 显示」手动入口。

## 改进

- 设备下拉框模板的文本宽度改为跟随控件宽度，不再固定截断在 62 像素；经典页较长的设备名也能显示更多字符。

## 打包

- 版本号提升到 0.2.0。
- 发布三种形态：
  - `FaderDeck-0.2.0-win-x64-thin.exe`（0.5 MB，单文件，需 .NET 8 Desktop Runtime）；
  - `FaderDeck-0.2.0-win-x64-selfcontained.exe`（63 MB，自包含单文件，首次运行把 WPF 原生库解压到 `%TEMP%\.net`）；
  - `FaderDeck-0.2.0-win-x64-portable.zip`（62 MB，自包含文件夹版）。
- 单文件必须加 `-p:IncludeNativeLibrariesForSelfExtract=true` 才是真正的单文件：默认值会把 `wpfgfx_cor3.dll`、`PresentationNative_cor3.dll` 等 5 个 WPF 原生库留在 exe 旁边，只复制 exe 会以 `DllNotFoundException: Dll was not found` 崩溃。
- `SatelliteResourceLanguages=en` 去掉未使用的本地化附属程序集，单文件体积从 68 MB 降到 63 MB。

## 已知限制

- 自动同步 GG 显示依赖能定位到 GG 进程窗口；定位失败时仅提示，不重试。
- 重新载入 GG 会把 GG 当前页面重置回 Sonar 主页，并有一次可见的闪动。
- 自包含单文件版需要往 `%TEMP%\.net` 写解压目录；若该路径不可写（例如进程以低完整性级别运行、`TEMP` 被策略重定向或磁盘已满），宿主直接退出，退出码 `0x800080A0` / `0x8000809F`，此时改用文件夹版 / thin 版，或设置 `DOTNET_BUNDLE_EXTRACT_BASE_DIR` 指向可写目录。
