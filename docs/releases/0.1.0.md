# FaderDeck 0.1.0

发布日期：2026-10-20

这是 FaderDeck 的第七个 Windows x64 自包含便携版本，新增 GG Streamer mode（主播模式）的控制能力。

## 使用方法

1. 安装并启动 SteelSeries GG，确认 Sonar 已启用；
2. 解压 `FaderDeck-0.1.0-win-x64.zip`；
3. 运行 `FaderDeck.exe`；
4. 单击系统托盘图标打开控制面板，右键图标可退出。

发布包为自包含便携目录，已包含 .NET 8 运行时，解压后直接运行 `FaderDeck.exe`，无需额外安装 .NET。

## 本次更新

- 面板新增「主播模式」页，对应 GG 的 Streamer mode；
- 可在经典与主播模式之间切换 Sonar 混音模式；
- 直播混音（streaming）与监听混音（monitoring）可分别调节 Master、Game、Chat、Media、Aux、Mic 的音量与静音；
- 每个通道都有入混音开关，状态直接来自 Sonar 的 `streamRedirections`；
- 支持「直播监听」开关，并在 Sonar 锁定该开关时显示为不可用；
- 新增硬件输出控制：耳机输出与线路输出的音量、静音，并显示当前生效的输出特性；
- 经典页在主播模式下会显示提示，说明该页音量只作用于经典混音；
- Sonar 发现改为 TCP 监听表加 `/mode` 探测，不再依赖进程枚举；
- 探针新增主播混音报告，可用 `--verify-streamer-writes` 做原值回环验证。

## 注意事项

- 切换 Sonar 模式后，GG 会重建虚拟输出设备，面板状态刷新会有短暂延迟；
- 主播混音音量没有 WebSocket 事件推送，面板打开时依赖 5 秒轮询同步；
- 经典混音与主播混音是两套独立音量，主播模式下的经典页改动会在切回经典模式后生效；
- 当前在 SteelSeries GG 116.0.0 / Sonar 1.104.0 上完成验证；
- 发布文件尚未代码签名，Windows 可能提示未知发布者；
- 当前提供便携压缩包，尚无安装器。
