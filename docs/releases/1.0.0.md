# 1.0.0

首个公开发布版本：重命名为 **GG FaderDeck**、接入新图标、配色对齐 SteelSeries GG，并把仓库整理成可直接公开的形态。

## 下载

| 文件 | 体积 | 需要 .NET 8 Desktop Runtime |
| --- | --- | --- |
| `FaderDeck-1.0.0-win-x64.exe` | 878 KB | 是 |
| `FaderDeck-1.0.0-win-x64-standalone.exe` | 63.4 MB | 否 |

两者功能完全一致。standalone 版首次运行会把 WPF 原生库解压到 `%TEMP%\.net\<应用名>\<哈希>`；若该目录不可写，可设置 `DOTNET_BUNDLE_EXTRACT_BASE_DIR` 指向可写目录，或改用 thin 版。

## 功能

- **经典模式**：六条通道的音量 / 静音 / 输出设备绑定；EQ 预设快速切换；主音量拖动时其余通道按比例跟随。
- **主播模式**：右上角切换经典 / 主播；直播与监听两套混音互不覆盖；胶囊开关选择进入当前混音的通道；「个人合成器」「麦克风输入」设备快捷切换。
- **应用路由**：按四张声卡列出当前应用，拖到另一张卡片即切换该进程输出。
- **实时同步**：通过 Sonar 的 WebSocket 事件同步音量，键盘媒体键或 GG 内的改动能反映到面板。

## 已知限制

- GG 只在启动时读取一次 `/mode`，在其外部切换经典 / 主播后，GG 已打开的页面不会自动重绘；把 GG 窗口关到托盘再打开即可。
- Sonar 的 HTTP 端口每次启动都会变化，程序通过 TCP 监听表 + `/mode` 探测自动发现。
- 经典模式下 Sonar 会拒绝主播混音的写入（返回 `Cannot be called in current mode`），程序会自动纠正模式后重试。
- 托盘图标依赖 `Shell_NotifyIcon`；若资源管理器以管理员身份运行，普通权限进程会被 UIPI 拒绝注册，此时以相同权限运行本程序即可。
