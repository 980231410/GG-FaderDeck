## 程序如何与 Sonar 通信

FaderDeck 只做两件事：

1. 读取 `C:\ProgramData\SteelSeries\GG\coreProps.json` 中的明文端口字段，或在必要时扫描本机
   loopback 监听端口并用 `GET /mode` 探测，从而找到 Sonar 的本地服务地址；
2. 对该 loopback 地址发送 HTTP 请求（读取音量、写入音量、切换模式等）。

客户端强制校验目标地址必须是 `http://` + 回环 IP，不连接任何外部主机。
程序不写注册表、不创建虚拟声卡、不处理音频流、不修改 `hosts`。
